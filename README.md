# crud-demo

Projet Java CRUD (Maven + JDBC + H2) - gestion d'etudiants en console.

## Ouvrir dans IntelliJ
1. File > Open > choisir le dossier `crud-demo` (celui qui contient pom.xml)
2. Choisir "Open as Project", attendre le chargement Maven
3. Verifier le JDK (17+) : File > Project Structure > Project SDK
4. Ouvrir `Main.java` et cliquer sur la fleche verte pour lancer
